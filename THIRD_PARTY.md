## Not included

No source code from other keyboard projects is included. Protocol facts learned from public projects are
re-implemented independently and credited in [docs/PROTOCOL_SOURCES.md](docs/PROTOCOL_SOURCES.md) and
[docs/RESEARCH_MATRIX.md](docs/RESEARCH_MATRIX.md). See [docs/LICENSE_NOTES.md](docs/LICENSE_NOTES.md).

Vendor software (AJAZZ drivers) was analysed locally for interoperability and is never redistributed.

The BY Tech adapter (`packages/protocols/src/families/by-tech/`, AULA and RK keyboards) re-implements
the protocol documented by [leisiji/AulaSofwareLinux](https://github.com/leisiji/AulaSofwareLinux)
(MIT, Copyright (c) 2026 aula contributors); the AULA F75 settings page used by its simulator and tests
is that project's published hardware capture. RK model facts (the R75's model code and firmware
generation) come from RK's driver configuration as published by
[vinc3m1/kludgeknight](https://github.com/vinc3m1/kludgeknight) (GPL-3.0); only the facts are used, no
code or files. Its key matrix, colour table, effect numbers and the per-board factory key tables
(`packages/protocols/src/families/by-tech/rk-web.json`, built by `pnpm rk-web`) are facts read from
RK's own web driver (drive.rkgaming.com); none of its code is used or redistributed.

The VIA, Vial, ZMK Studio and libhmk adapters are written from public specifications and firmware
sources, facts only: VIA (the-via/app, the-via/reader, GPL-3.0: command layouts, layout-option bit
packing, custom-menu value encoding, KLE legend positions), Vial (vial-kb/vial-qmk and vial-gui,
GPL-2.0: Vial commands, QMK-setting ids and sizes; the setting labels are OpenKey's own), ZMK Studio
(zmkfirmware/zmk-studio-messages and zmk-studio-ts-client, MIT; zmk-studio, Apache-2.0: messages,
framing, parameter encoding) and libhmk (peppapighs/libhmk and hmkconf, GPL-3.0: commands, keycodes,
metadata and layout placement). The XZ/LZMA2 decoder and the protobuf wire codec are OpenKey's own
code written from the public format specifications; no runtime library is used for either. The VIA
board index (`packages/devices/src/via-index.json`) holds only USB IDs and names from
the-via/keyboards (GPL-3.0), facts with no definition content.
