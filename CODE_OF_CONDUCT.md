# Code of conduct

OpenKey follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be kind and specific. Critique code and evidence, not people. Harassment, insults and personal
attacks are not accepted in issues, pull requests or discussions.

Report unacceptable behaviour privately to the maintainer through a
[GitHub security advisory](https://github.com/BakulBd/openkey/security/advisories/new) marked
"conduct". Reports are handled confidentially.
